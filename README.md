# Bot Rekap

Bot Telegram untuk manajemen rekap dan transaksi dengan fitur Last Win tracking.

## 🎯 Fitur Utama

### Last Win Management
- 📱 `/open` - Buka game untuk mengatur Last Win dengan DEV & ROL
- 🏆 `/lw` - Lihat Last Win terakhir
- 🔄 `/resetlw` - Reset Last Win (admin only)

### Rekap Lengkap
- 📊 `/rekapwin` - Rekap win dengan format lengkap (DEV, ROL, GAME, SALDO)
- 📊 `/rekap` - Hitung total K dan B
- 🏆 `/win` - Hitung winner dengan fee
- 📋 `/list` - Auto list dari reply

### Manajemen Saldo
- 💰 `/balance` - Cek saldo (PM)
- 💳 `/depo [jumlah]` - Deposit (PM)
- 💸 `/wd [jumlah]` - Withdraw (PM)
- 🔄 `/bulatkan` - Bulatkan saldo (PM)
- 📉 `/kurangi [jumlah]` - Kurangi saldo user (admin only)

### Fitur Grup
- ✅ Registrasi grup otomatis
- 🔗 Anti-link protection
- 👥 Tag admin
- 📝 Peraturan grup
